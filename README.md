🩺 Sugarease – AI-Powered Diabetes & Health Monitoring App

Sugarease is an AI-powered health monitoring application developed as a Final Year Project (FYP). The app focuses on supporting individuals with diabetes by combining machine learning, computer vision, and mobile-first design to provide health insights, food analysis, and activity tracking in one unified platform.

🚀 Features

📸 AI-Based Food Scanning
Analyze food images using a trained deep learning model to estimate nutritional insights.

📊 Health Analytics Dashboard
Visualize BMI, activity data, and trends through interactive analytics.

🏃 Activity Tracking
Step counter and workout streak tracking to encourage a healthy lifestyle.

🎥 Educational Video Hub
Curated health and fitness videos integrated directly into the app.

🔐 User Authentication
Secure login, password management, and session handling using Firebase.

🤖 AI Integration
Backend powered by trained ML models (TensorFlow / TFLite) with API support.

2️⃣ Install Dependencies
